# Puerto Rico: permit registers in Spanish

The [Planning Board’s official MIPR permit service](https://sigejp.pr.gov/server/rest/services/MIPR/Permisos/MapServer) spans multiple record systems. The [Puerto Rico statistics institute](https://www.estadisticas.pr.gov/productos/mapa-interactivo-de-pr) identifies MIPR as the Planning Board’s official map; its [PEMAS description](https://www.estadisticas.pr.gov/productos/pemas---permisos-de-construccion) explicitly describes permit **applications**, not a list of issued projects.

This snapshot includes 33 dated case dispositions across San Juan, Carolina, Manatí, Guaynabo, Mayagüez, Juncos and Toa Baja. Twelve are construction, electricity-generator, earthwork or consolidated-use permit records: eleven approved in the register and one explicitly expired. None establishes that a campus is operating. The remaining 21 include nine categorical-exclusion environmental determinations, recommendations/pre-consultations and a March 2003 Planning Board location clarification. Dates are the register status dates, not a fabricated signature, construction start, expiry, or operating date. These government registers establish official dispositions, not access to the executed instrument. The government’s [PCD manual](https://docs.pr.gov/files/OGPe/Manuales/OGPe%20Manual%20Externo%20PCD%20-%20FINAL.pdf) makes clear that **PCD is a pre-consultation**, not a construction permit.

[SuperSIP](https://sigejp.pr.gov/server/rest/services/MIPR/Permisos/MapServer/2), [SIP](https://sigejp.pr.gov/server/rest/services/MIPR/Permisos/MapServer/8), [ARPE](https://sigejp.pr.gov/server/rest/services/MIPR/Permisos/MapServer/16) and the [JP consultation register](https://sigejp.pr.gov/server/rest/services/MIPR/Permisos/MapServer/20) were searched by project description and available operator fields. The thematic sublayers repeat the same bases and are excluded. Returned object-ID sets were completely retrieved, then deduplicated by layer and object ID. Eight searches yielded 536 hits, or 530 distinct source features; 497 were withheld. Examples include school computer labs, a company providing data-center equipment, an inactive file with no approval evidence, and generic wireless antenna colocation. The old ARPE registry includes industrial Microsoft data-center construction/use files in Humacao, but only shows their filing dates. The later Critical Hub Caguas case is awaiting inspection. Neither is counted as an issued permit. Company names, Codisa/NAP del Caribe/PR-DC keywords and fiber runs alone do not establish a facility.

A representative [WorldNet construction row](https://sigejp.pr.gov/server/rest/services/MIPR/Permisos/MapServer/2/328367) and its related environmental determination have **different file IDs**. [The Toa Baja project](https://sigejp.pr.gov/server/rest/services/MIPR/Permisos/MapServer/2/1007844) likewise has separate procedural records. FIBERX has an [expired 2024-series file](https://sigejp.pr.gov/server/rest/services/MIPR/Permisos/MapServer/2/893210) and a [different approved 2026-series file](https://sigejp.pr.gov/server/rest/services/MIPR/Permisos/MapServer/2/1046640); these are two instruments, not a contradictory status on one permit.

Run `python3 scripts/collectors/puerto_rico/history.py` offline. `--fetch` retrieves missing search batches, never silently replaces an existing response. Each case has its own official query link, source object ID, digest, original Spanish procedure/status where available, and the published municipio. `data/history/puerto_rico/held.json` retains the individual keys of withheld candidates.
