# Local ordinance and state permitting checks

This is a set of ordinance provisions, not a survey asserting every municipal code was exhausted. The cutoff is November 15, 2026. Start with the directory facility-count ranking in data/national/priority.csv. For this pass, Virginia, Texas, Ohio and Arizona already had detailed work; California, Illinois and Oregon are separate assignments. The high-priority gap search included Georgia (#5), New York (#7), Florida (#9), Washington (#11), New Jersey (#13), North Carolina (#15), Minnesota (#16) and Michigan (#19). The Louisiana addendum supplies design and construction details requested for the original parish pilot. Market rank determines the search queue; it never establishes jurisdiction, code applicability or permit prevalence.

Read data/national_rules_terra.json for provision-level records, authority, legal units, source URLs and article/section locators. The [source manifest](../data/national/rules_terra_sources.json) distinguishes signed law, codified text and council exhibits from minutes, state adoption-register entries and government publicity corroborating adoption. Passing ordinances and underlying approval exhibits can be linked; a first reading, staff recommendation or public notice by itself does not qualify. Where the source says the law becomes effective upon publication or filing, the unknown filing date remains null. Dated temporary measures should be checked for repeal, expiry or subsequent extension before a parcel-specific determination.

Run `python3 scripts/ordinances/rules/audit.py` from the project. It reads original files offline, pins their SHA-256, calls exactly the project's PDF/HTML parser, stages content-addressed raw files/text/link lists, and writes **only** cache/national_rules_terra/reviewed_index.json plus its audit. It does not edit output/source_index.json. The shared importer merges the side index. cache/national_rules_terra/visual_reviews.json keys signed scanned pages by rule, SHA, locator, reviewer and read date. Look for the reported split between original-backed rows and held rows: a government web index showing a law is not a substitute for the original bytes. For a fresh capture, retrieve the cited public original into cache/national_rules_terra, check its adoption and content, review the affected clauses, then update its filename and digest in the source manifest intentionally. A changed file will fail replay; it will not inherit the old disposition.
