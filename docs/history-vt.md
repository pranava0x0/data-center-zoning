# Vermont: Act 250 and water permitting for VELCO

The [state's public Act 250 registry](https://anrweb.vt.gov/ANR/Act250/default.aspx) allows description search and displays case documents using ASP.NET form postbacks. Four statewide description queries (data center, data centre, server room, data processing) return one explicit project, [1R0372-10 in Rutland Town](https://anrweb.vt.gov/ANR/Act250/Details.aspx?Num=1R0372-10). The public case led to a signed Act 250 amendment, a two-year construction discharge authorization, an explicitly draft operational water permit, and the agency reviewer’s case-specific statement that no UIC permit was necessary. The municipality is the Town of Rutland, not the City of Rutland. Exhibit filing dates are used only as labeled and not substituted for underlying authorization dates. The land-use permit covers a 6,845-square-foot data center plus a separate enclosure for two standby generators. The statewide land-use register is not a statewide inventory of developments: exempt projects, permits using other wording, and municipal-only cases will be missed.

The [PNNL inventory](https://github.com/IMMM-SFA/datacenter-atlas) has one Vermont marker: a 130-square-foot building at The Putney School in Windham County. It cannot support a meaningful market ranking. No source established a permit authorizing that specific small structure. No inference is made from unrelated school campus permits.

Run `python3 scripts/collectors/vermont/history.py` for offline replay, or `--refresh` to resubmit all four public searches and download the exhibits by the site's own View actions. Archived documents carry checksums. Citations use the stable case page with exhibit identifiers because the state's PDF download URLs are temporary. The refresh fails for review if a search returns a new project, preventing silent omission. A conditional/draft requirement is not counted as an issued instrument.
