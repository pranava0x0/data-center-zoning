## COMPASS: what transfers and what does not

I opened the original cached XLSX distributions for [wind](https://data.openei.org/submissions/8519), [solar](https://data.openei.org/submissions/8602), [geothermal heat pumps](https://gdr.openei.org/submissions/1876), [geothermal electricity](https://gdr.openei.org/submissions/1877) and [transmission](https://data.openei.org/submissions/8787); each hash matched the pinned official distribution in the [catalog](../data/compass_sources.json). The live OEDI landing pages for wind/transmission returned HTTP 429 during the spot-check. I compared the feature sheets, headers and examples, and read the transmission column/type dictionaries. The existing [COMPASS check](../output/compass_crosscheck.json) reports 34,466 upstream features. That is an upstream regression check, not a successful import of the local release.

| Upstream field or unit | Atlas input and integration decision |
|---|---|
| State, County, Subdivision, Jurisdiction Type, County Subdivision FIPS Code | Use typed jurisdiction joins and full state names. Preserve leading zeros. A county/municipal/tribal/service-area ID is not automatically a county subdivision FIPS; use null where inapplicable. Of 312 published rows, eight have no mapped GEOID. State-level requirements must survive a local-only GIS export. |
| Feature, Value, Units, Summary | Publish a versioned, flat **feature** export plus a technology dictionary. The current [published CSV](../output/published.csv) is one row per reviewed rule/requirement with thresholds encoded as JSON; 73/312 rows have structured thresholds. A qualitative feature legitimately has no number. Example: Fairfax residential setbacks require two feature rows (200 feet building; 300 feet equipment), linked to one original rule; preserve the intervening-building alternative. Keep gross floor area as area, not setback distance. Do not infer a number from prose without review. |
| Section, Ordinance Year, Source URL | Map original locator and URL, take year only from supported enactment/amendment/effective evidence under the chosen release definition. Do not use crawl date. Keep exact dates, official quote, issuer evidence URL, comparator, scope and exceptions in sidecar fields with stable IDs. Example from the actual solar workbook: a Roads value of 1.1 is a structure-height multiplier, not 1.1 feet. Matching numeric columns alone is insufficient. |
| Technology-specific columns and meanings | Wind adds setback adder and min/max distances; solar has setback adder; the transmission workbook uses the shorter core. Its “Franchise” is an **electric** utility franchise and “Setback - Roads” describes separation. Neither is permission to lay fiber in a highway. Define reviewed telecom features for occupancy/encroachment, excavation and restoration, traffic control, pole/conduit access, easement and franchise rather than borrowing the electric legal meaning. Distinguish installation method from permission. |
| Unit of observation and permissible records | Publish applicable enacted ordinance features in the COMPASS-style table. Preserve separate searchable geography/discovery results and explicit evidence gaps. Keep agency guidance, applications, hearing notices, signed instruments, individual decisions and timeline events in linked extension tables. Count a permit once even if there are multiple events or route jurisdictions. A state agency can issue work authorization inside a county; county location is not county authorship. No verified end-to-end import into NLR's viewer, ingest pipeline or model was found; no NLR endorsement is implied. |
