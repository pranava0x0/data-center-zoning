# US Army Corps of Engineers: federal project history

The November 16, 2026 snapshot includes **120 federal events in 20 states**: 29 individual permit issuance events, two general-permit verifications, 48 approved jurisdictional determinations, 22 environmental assessment milestones, 15 pending-permit actions and four public notices. The 31 issuance/verification events refer to **27 distinct Army file numbers**, not 31 sites or necessarily 27 separate instruments. A single file may contain an earlier issuance and a later modification or reissuance. The public data do not establish whether a permit remains effective. Dates observed: March 12, 2010 through November 13, 2026.

The [USACE public ORM portal](https://permits.ops.usace.army.mil/orm-public/) makes selected regulatory data publicly available, not a full national census of every general permit verification or all past filings. The two Illinois verifications are in the Section 214/WRDA program. A jurisdictional determination addresses geography; it is neither a project approval nor a permit. An agency may complete an environmental assessment without issuing a separate authorization. Consultation actions are retained as nested agency fields for context, not converted to independent permits. The agency's project point is a representative location, not a site boundary.

**Replay:** `python3 scripts/collectors/federal/usace_regulatory.py`, then `python3 -m unittest discover -s tests -p 'test_federal_corps.py'`. The default is completely offline. `--fetch` fills missing known search/case pages, documents and point lookups. For a new observation date, start a new snapshot rather than mixing vintages in the checked-in manifests. The cutoff and snapshot-wide regression counts must be revised for a new release.

1. The public ORM [file search](https://permits.ops.usace.army.mil/orm-public-api/permits/search?q=%22data+center%22&da=true&max=200&start=0) returns GeoJSON features and a total. Search `da=true` for phrases, spelling variants and named operators, then request `sa=true` with `identifier:"…"` for each eligible file's underlying actions. Check pagination totals, file ID, record type and stable IDs on replay. Entries in the DA search are not additional actions.
2. The 28 queries found 142 unique candidate IDs. Sixty unconfirmed candidates are retained separately, including an unrelated sawmill adjoining Amazon Creek. Publish a case when its project name explicitly describes the use or a primary district notice independently establishes the sector; do not accept an operator name alone. Associated infrastructure labeled by the issuer, e.g. the Raging Wire duct package, is explicitly identified as such rather than being treated as a new data center.
3. Independently screen every one of the 129 notices in the [USACE Regulatory Request System](https://rrs.usace.army.mil/rrs/public-notices) listing snapshot and reconcile by Army file number. The public list also supports a read-only POST with keyword and page arguments. Keyword-only queries missed both Ohio projects named after local features. Four district notices qualify on explicit name, description or keywords. Five notice/plan PDFs are pinned, including the [Huntington District's Dutch Run notice](https://publibrary.sec.usace.army.mil/api/download?id=ba192119-3bf3-4230-bde7-ea17674289f8&filename=Public_Notice%20Dutch%20Run%20Technology%20Campus%202026-959.pdf&token=&preview=true). The list snapshot is not an archive of every prior public notice.
4. Intersect every distinct ORM coordinate with [Census TIGERweb county boundaries](https://tigerweb.geo.census.gov/arcgis/rest/services/TIGERweb/State_County/MapServer/1). All 84 distinct points matched exactly one county. Use the Census-derived state, separately record the geographic method, and label the computed county as `census_county`. Use `details.county` only for an explicit district-reported county, with location agreement when joining it to ORM.
5. All records link to government sources. Where ORM links to an official `.usace.army.mil` determination PDF, archive it when permitted; 13 were retrieved. Another 24 document URLs did not pass host robots preflight and remain explicitly identified. Institution-hosted non-government-domain documents were not substituted. The archived AJD memoranda are agency determinations, not signed construction permits. For [ATL088](https://permits.ops.usace.army.mil/orm-public-api/permits/search?q=identifier%3A%22SAS-2023-00094%22&sa=true&max=200&start=0), USACE's official file separately confirms conditions and the dates of two permit issuances. Neither the data register nor an EA should be described as a copy of the executed permit itself.

The `data/history/federal/usace_regulatory/*` manifests preserve request URLs, form inputs, agency-reported totals, hashes, candidate exclusions and retrieval failures. Raw responses are compressed under `cache/history/corps/`; `output/history/federal/usace_regulatory/<state>.json` holds state slices. The attribute `details.federal_issuer` distinguishes these records from state and municipal actions; `details.corps_file` is the cross-register linking field. Under this identity rule the [Richland Parish Army file](https://permits.ops.usace.army.mil/orm-public-api/permits/search?q=identifier%3A%22MVK-2024-00740-KC%22&sa=true&max=200&start=0) has separate September/October 2026 NEPA/application records, distinct from the earlier December 12, 2024 district public notice identified locally as MVK-2024-740.

## Two Virginia files that a name search missed

The original register search above counted actions whose facility descriptions used data center terms. Two additional Norfolk District files use the names *Timber LVL* and *Dulles Digital/Loudoun* in ORM. [The Digital Library collector](../scripts/collectors/federal/usace_virginia_prior_actions.py) ties each to a project description in an actual federal notice, then queries ORM by its exact file identifier. Nine dated events add two distinct county-level docket keys. A library compound object is a list of documents; the collector follows its public-notice child to the PDF and checks the raw bytes. An application PDF would not establish issuance.

- **Mecklenburg County:** [The December 2025 notice](https://usace.contentdm.oclc.org/digital/api/collection/p16021coll15/id/10722/download) identifies the original issue as October 1, 2021, its modification as August 28, 2024, and its status at reapplication as expired. ORM records the original action on October 4. The atlas keeps one original issuance with both dates and records the separate March 10, 2026 issuance. Its current status is unconfirmed. The older notice's comment deadline is not an expiry date. The actual agency PDF uses the 2021 case number, correcting the 2011 year shown in a district web headline.
- **Loudoun County:** The [July 2020 public notice](https://usace.contentdm.oclc.org/digital/api/collection/p16021coll7/id/14770/download), the February 2021 standard permit recorded by ORM, the 2022 jurisdictional determination and the [January 2026 modification notice](https://usace.contentdm.oclc.org/digital/api/collection/p16021coll15/id/10790/download) concern one file. No approval of the 2026 request was inferred.

[The non-Virginia library pass](federal-corps-library.md) adds five events in Ohio, Illinois, Oregon and Louisiana. Only the Ohio Phase I nationwide-permit verification adds a permit key.
