# Local ordinance search

The [ledger](../output/local_screen.json) records the jurisdiction, source of its website address, pages actually read, matching passages, and connection or access errors. The [coverage check](../output/local_screen_checks.json) reconciles the Census geography list and verifies the hash of each stored page. No search result changes the number of ordinance rules until an adopted provision or other authoritative document is read, cited and verified.

The [collector](../scripts/ordinances/discovery/screen_local_sites.py) checks a government entry page and up to two linked planning, land use, zoning or code documents. It honors published crawl policies. It does not infer that a locality has no data center ordinance because the home page failed to open, a code viewer requires JavaScript, or a search found no matching words. Some leads concern proposals or project news. For example, the search found a **draft** in Franklin County, Indiana, and an **adopted** temporary pause in Wabash County. Only the adopted Wabash rule was added on that evidence.

Website discovery uses the [CISA .gov registry](https://get.gov/domains/), state directories, [Arizona State University’s local government guide](https://libguides.asu.edu/salad/cities), the Census Bureau’s [2022 Government Units Listing](https://www.census.gov/data/datasets/2022/econ/gus/public-use-files.html) (General Purpose sheet, active units, matched by FIPS plus name), and [UScityURL](https://github.com/caimeng2/UScityURL) (2022 municipal site roster, matched by GEOID). Supplementary county website leads from Wikidata require an exact US county FIPS match. The discovery service rate-limited some lookups; those were not successful searches. Older domains may move or expire. Registry and directory matches are leads to official materials, not legal authority.

Run `python3 scripts/ordinances/discovery/screen_local_sites.py --fetch` for the next live pass; completed URL attempts are cached. The normal offline build consolidates the archived visits. Failed fetches and places still without a direct site are counted separately. The frame includes county subdivisions: a Census boundary alone does not establish an independent zoning authority. Source-specific townships, counties and cities can overlap.

For the places without a readable direct source, the [second pass](../scripts/ordinances/discovery/screen_indirect.py) checks the geography name near data-center terms in the archived same-state webpages and regulatory documents. [Per-place results](../output/indirect_screen.json) include how many documents were in the index and any matching passage. A matching township name may be shared by more than one county. This can locate a lead; it cannot clear a place for construction.

The [township roster](../data/screen_rosters/townships.csv) adds 363 links from the Ohio Township Association and Indiana's state township directory, joined by county and township name. For shared county and state portals, only pages on the listed township path count toward direct coverage. The [directory audit](../data/screen_rosters/townships-audit.json) records unmatched names and places without links.
