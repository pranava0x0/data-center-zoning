# Pennsylvania

The [state's project register](https://gis.dep.pa.gov/DataCenterPermitTracker/) links 76 proposed data centers to 408 potential authorizations. The collector joined the two official CSV tables by DEP project ID. It excluded 282 authorization types marked “Not Yet Submitted” and one undated federal consultation. The remaining 125 state entries keep the submission date and the separately reported status. An issued amendment is not counted as another permit when the instrument number is unchanged. Water crossings, stormwater, fuel tanks, site cleanup and sewage planning are separate topics.

[County and city priorities](../data/history/pennsylvania/rank.json) use the same IM3 marker and Census-boundary method as Ohio. Multiple markers can represent buildings on one campus. The DEP register was searched statewide, including locations outside those top counties. A project spanning several municipalities keeps its source names in the card details without being credited in full to each city.
