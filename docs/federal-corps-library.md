# U.S. Army Corps of Engineers Digital Library: bounded search of public permitting records

Twenty exact-phrase searches across the Corps’ **Public Notices and Jurisdictional Determination Forms** and **Regulatory Information** collections returned 95 distinct first-page items. Queries included variant spellings of data center, cloud computing, server farm, hyperscale and five named developers. The raw search receipts report the total versus the up-to-50 returned for each term; repeated items across terms count once. Project management reports and other general library collections were not counted or published. This is a deliberately bounded candidate review, not the complete Corps docket. Of 14 targeted metadata records, nine original downloads were attempted; eight were valid PDFs. Unread items are not negative findings.

Run `python3 scripts/collectors/federal/usace_digital_library.py` from the project root for offline replay; use `--fetch` only to add missing cases/search responses. The script requires PyMuPDF. Evidence is archived in `cache/history/corpslibrary` and `cache/history/corpslib_queries`, with two SHA-256 manifests in `data/history/federal/usace_digital_library/sources.json` and `queries_sources.json`. `data/national/corps_library_audit.json` gives per-query discovery results, dispositions and docket overlaps. Sources are the Corps’ own library copies of district documents; the archive is not a live permit-status register.

The five events use the register **Army Corps Digital Library project actions** and four separate state files. The classifier in the same module returns non-permit application for notices, non-permit decision for the AJD, and one unconfirmed authorization under the same USACE ORM file-key convention for the verified Ohio NWP. Normalized district, year, zero-padded docket sequence, and event date guard against publishing already captured actions across archive variants; a same-file, different-date observation is substantively reviewed before inclusion.
