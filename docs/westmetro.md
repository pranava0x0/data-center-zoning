**Local rules.** [Santa Clara's official council report](https://santaclara.legistar.com/LegislationDetail.aspx?ID=8260886&GUID=2791DE9D-56B5-49B5-9998-BC1264149D06&FullText=1) distinguishes three districts allowing stand-alone facilities with a conditional use permit from HO-RD, which allows only ancillary data centers. Ancillary use is subordinate, limited to 20% of site building area and 9 MW. Architectural review and reclaimed water are separate obligations. The [San José decision attachments](https://sanjose.legistar.com/View.ashx?M=F&ID=16056383&GUID=BF0EDB0E-476A-4856-AA8E-F3CF50BE805F) establish the special-use route in that city's Industrial Park zone. No transfer of Santa Clara thresholds to San José.

**Permit history.** The [Portland register](https://www.portlandmaps.com/arcgis/rest/services/Public/BDS_Permit/MapServer/22) and [city guide](https://www.portland.gov/ppd/portlandmaps-help-guides/portlandmaps-general-search) distinguish file classes and dates. Query searches DATA CENTER, DATA CENTRE, DATACENTER and SERVER FARM across DESCRIPTION and WORK_DESCRIPTION. First fetch all matching object IDs, then fetch batches of up to 75. Output equals the entire matched ID set, without parcel replication. FOLDERKEY identifies each distinct file; APPLICATION is the readable case number. ISSUED dates are independent of status and use the service's advertised America/Los_Angeles timezone. Dates span April 7, 2000–October 12, 2026. Statuses: 103 Final, 18 Issued, 3 Completed, 1 Closed, 1 Expired, 1 Under Inspection. Classes: 81 facility, 24 electrical, 7 fire systems, 6 mechanical, 5 commercial building, 2 early-assistance files, one noise variance and one public registry inquiry. One Final file lacks an issue date. Nonpermit inquiries and noise files are excluded from issuance counts; an old Issued label is not confirmed current validity. This includes individual server rooms, trade work and renovations. Use only source-reported county (9 entries lack one). Full descriptions are kept in archived government responses; the exported file avoids replicating contact information appearing in some notes.
