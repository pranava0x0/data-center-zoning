Replay: run the FAA bulk collector first, then `python3 scripts/collectors/federal/faa_letters_california_energy.py`. To recapture the five primary PDFs use `--refresh` with PyMuPDF available. The manifest pins each original PDF and its per-page text by SHA-256. The parser verifies the docket cover, the FAA letterhead, study number, printed issue date, action heading, structure, California location, and signature control number. It uses the embedded text on the decision pages, without additional OCR; incidental OCR-like marks on map sheets carry no evidentiary weight. Filed covers, site plans, attached maps, notices required of a project proponent, and contacts are not independent decisions. A changed or illegible signature or new decision template requires review; publishers should not accept guessed OCR values. A signature control number is present on each original; no cryptographic signature validation is claimed.

`data/national/federal_aviation_letters_audit.json` reconciles verified and suppressed actions by filing. Deduplication compares study number, normalized decision label and decision date against the published bulk release and other signed letters. Seven study numbers match a bulk study, but none have the same decision and day. Only the FAA-reported city is used; county is not inferred. Discovery is bounded to five docket filings and does not establish statewide completeness.
