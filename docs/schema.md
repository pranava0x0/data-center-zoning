# Data model and replication
The unit is a **provision**, not an ordinance, data center, claim of capacity, or blanket permit for a county. One government can issue several instruments; a single instrument can produce several linked records. Keep the issuing authority, geographic indexing area and applicability of a project separate.

| Relation | Key and meaning |
|---|---|
| Curated research inputs, `data/*.json` named in `collect.rules()` | Stable `id`, two-letter indexing `state`, issuing `authority`, `jurisdiction`, `level`, `scope`, `topic`, `summary`, legal/source `status`, `url`, `locator`, short literal `evidence`. Optional `district`, `trigger`, `thresholds[]`, `effective`, `adopted`, `expires`, `geoid`. Blank dates are unknown, not the date of website retrieval. |
| `data/pathways.csv` | One reviewed use path per area/condition and research ID; a rule may have more than one. Permitted use, special exception, special use permit, conditional use permit, planned development, rezoning, prohibition and temporary pause are distinct. No classification from absence. A subset is coded; many records concern separate technical permits. |
| `output/source_index.json` + `output/fetch_history.jsonl` | Request URL, final URL, retrieval time in UTC, adapter, bytes, SHA-256 of original and text, or error. Each raw source and extraction is keyed by original digest. On fetch failure the active index records failure, not a fresh validation; archived bytes and history survive. |
| `data/review_pins.json` + visual reviews | Research-row digest and original source digest; for a scanned page, a separate digest of the agent's documented visual review. Cite the page, not a transcription presented as native text. Pins detect change; they are not signatures of local counsel. |
| `output/rules.json`, `rules.csv` | All research rows including holds; derived category, pathways, evidence check, retrieved/source hash, and Census map key. Default viewer and filtered CSV omit held records. Select only `snapshot_match` and `visual_source_check` for the default published subset. |
| `output/extracted_values.json` | Repeatable bounded numeric recipes: metric, comparison, value, unit, condition, source hash and underlying provision. If comparison context is missing or produces competing numbers, return for review. No automatic propagation into a zoning permission. |
| `output/jurisdictions.geojson` | Joinable state/county multipolygons and Census internal points for places/townships with researched records. Properties separate published/held IDs; records without geometry remain in the master table. Neither polygon nor point represents parcel eligibility. |
| `output/coverage.csv`, `worklist.csv` | 2025 Census geography, layer, state, point, coverage status, possible official domain and next collection action. State ranking is about the research queue, never legal authority. |
| `output/virginia_screen.json`, `discovery_*.json` | Discovery history, candidates, unvisited leads, errors/empty responses; candidate documents are not ordinance findings. Virginia directory rows are preserved even if a Census join is unavailable. |

**Scope and type.** Inputs preserve the researcher's original topic and terms (including “guidance” / “agency_guidance”); category and pathways are normalized for comparison. An agency implementation page, adopted code, signed amendment, utility policy and pending proposal are different kinds of evidence. A conditional use in an industrial district, a construction permit for disturbance, an emissions threshold for an engine, and approval for utility discharge can all apply simultaneously. Distinguish total facility MW vs IT load vs utility request; building vs campus floor area; average vs peak flow; ground vs surface withdrawal; sanitary sewer vs direct discharge; strict vs inclusive comparisons; permanent vs temporary works. Preserve exemptions and grandfathering in the same row/linked records. Numeric fields on authored records are interpretations; only the separate bounded recipes are auto-extracted.

**Geography.** [Census Gazetteers](https://www.census.gov/geographies/reference-files/time-series/geo/gazetteer-files.2025.html) supply state, county/equivalent, active incorporated places and active county subdivisions. The [2025 generalized cartographic files](https://www.census.gov/geographies/mapping-files/2025/geo/carto-boundary-file.html) provide state/county outlines; place markers are internal points, not service or zoning polygons. State and regional authorities, parishes and independent cities cannot all be spatially inherited from a county. The [Virginia locality directory](https://www.virginia.gov/local-government/) supplements name-matched [CISA .gov candidates](https://get.gov/about/data/); public websites with other suffixes are not presumed absent. More than one layer can represent the same government; names and ZIP codes do not establish authority. Census functional status is only an inventory filter. Towns spanning county lines, charter exceptions, annexations, tribal boundaries, utilities, home-rule provisions and specific parcel/zoning maps need separate checks. Tribal, regional and federal records without a geography match are listed and deliberately have no county polygon.

**Collection loop.** Choose a row in the worklist. Verify the issuer. Add the issuing government's planning/code/permit seed in `data/seeds.json`; use the narrowest official landing page available. `collect.py discover` ranks outgoing links by terms, follows bounded same-host links, keeps external code-host links as leads, and writes text spans with offsets. Static HTML/text, text PDFs and DOCX have deterministic adapters; scans, dynamic portals, denied URLs, corrupted text and redlines need separate handling. Start with primary code/adopted text; use agency instructions for its own administrative steps. Locate an effective instrument and check amendments, exceptions, exhibits and maps. Write an attributed research row, fetch and compare it, inspect apparent negatives. Confirm publisher hosting relationships before adding a third-party link. Keep proposals, hearings and utility announcements as discovery evidence until authoritative disposition is known.

**Updating.** Rebuild offline for the 2026-11-15 edition. Review changes on a new edition/branch: refresh sources, compare old/new bytes and relevant passages, re-evaluate applicability and dates, then replace the affected pin after documenting the decision. `--seal-new` never overwrites an existing pin. Preserve old inputs/exports/version history before declaring a new edition; changing the displayed date alone is not a review. An expired or stayed moratorium must not be left in the current edition. Keep an independent reviewer and adjudication log for production, including a random stratified hand-search of negatives, missed clauses, competing zoning vintages, and redline interpretation. There is no measured statewide recall or legal-expert signoff for this pilot.

**Permit counts and screen copy.** The consolidated history records retain the original agency status and date role. The additional permit key, bucket, representative flag and explanation are defined in [permit-status.md](permit-status.md). History contains more than permit numbers. The map and its filtered permit list use the same representative rows. `data/card_copy.tsv` supplies short headings and summaries; the original claim, quoted evidence and locator remain available.

[Zoning pathway evidence](../output/pathway_evidence.json) binds each published district classification and its conditions to the parent source URL, source bytes and locator. The [crosswalk check](../scripts/pipeline/check_pathway_links.py) fails if a classification, qualifying condition or citation changes without review. Entries whose parent source is withheld are reported separately and do not appear in the default rule results. This is a drift check, not a substitute for reading the use-table row, heading and exceptions.
