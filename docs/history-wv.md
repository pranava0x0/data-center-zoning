# West Virginia: project applications and enforcement

The PNNL snapshot has just two markers in West Virginia: one each in Kanawha and Morgan counties. That is insufficient to infer a concentration of planned megawatts. [WVDEP](https://dep.wv.gov/news/Pages/Public-Comment-Period-and-Public-Participation-Opportunities-for-Monarch-Cloud-Campus.aspx) documents a much newer, dedicated off-grid power application for Monarch in Mason County plus two distinct State Waters permit applications. The underlying evaluation fixes an April 20, 2026 receipt and May 26 revised information; the published October public meeting and November comment dates are not permit decisions. [WVDEP's July release](https://dep.wv.gov/news/Pages/WVDEP-Issues-Enforcement-Order-Following-Stormwater-Violations-at-Monarch-Cloud-Campus-Construction-Site.aspx) records enforcement on the construction stormwater permit, with corrective actions and a partial stop-work direction. The release does not name the underlying permit number or the order number. “Monarch stormwater order (number not stated)” is a descriptive reference and is excluded from instruments.

The [state air applications register](https://dep.wv.gov/daq/permitting/Pages/NSR-Permit-Applications.aspx) reports Cumulus R13-3782, received July 22 in Putnam County; the linked application expressly identifies a data center. No issuance is claimed. By contrast, [WVDEP's evidence in the Ridgeline appeal](https://aqb.wv.gov/AppealsDocuments/2025.10.15.%2025-02-AQB.%20Certified%20Record%20Part%206%20of%206.%20Pages%20546%20-%20653.pdf) says R13-3713 did not include a data center and did not identify the end user. It was excluded. The [Berkeley County project announcement](https://westvirginia.gov/4-billion-data-center-campus-planned-for-berkeley-county-positioning-west-virginia-for-the-ai-and-cloud-economy/) is not a permit. No case-level municipal authorization in the two highest marker counties was established; applications and an order in other counties are kept explicitly distinct from issued authorizations.

`python3 scripts/collectors/west_virginia/history.py` checks raw-byte hashes and normalizes 13 events offline. Use `--refresh` to snapshot the project documents, government index and geometry. The sample has no proven, numbered newly issued site-specific permits; that is not a statewide zero.
