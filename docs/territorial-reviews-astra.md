# Territorial permit-history discovery: Guam, American Samoa, CNMI and USVI

Reviewed on November 16, 2026. The geographic result here is **one Guam project with four additional referrals; no verified data-center-specific local file in the other three sampled registers.** An unrelated or unidentified commercial project is not evidence that a territory has no data centers. Puerto Rico's separate [Spanish-language register analysis](history-pr.md) covers seven municipios.

**Reproduction.** Run `python3 scripts/collectors/guam/land_use_referrals.py` for the Guam output and `python3 scripts/collectors/territories/case_screen.py` for the frozen notice screen. Each original has a SHA-256 and byte count in its territory-specific `data/history/territories/{as,gu,mp,vi}_supp_sources.json` manifest and is stored losslessly under `cache/history/<territory>/`. The [screen result](../data/history/territories/territorial_review.json) lists exact URLs, evidence excerpts, pages needing OCR, and OCR hashes. Optional `scripts/collectors/territories/notice_ocr.py` regenerates OCR snapshots on macOS; text recognition can misread words. `scripts/collectors/territories/notice_indexes.py` fetches missing public files; a new batch requires a new snapshot. No news outlet or company promotional statement was treated as an issuance.
