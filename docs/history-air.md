# Virginia air-permit history: agency issues, approvals and applications

The state list answers “what air permit did DEQ list for this data center?” It does not answer “when did the building open?”, “what zoning use was granted?” or “are these all prior authorizations?” A registration number identifies the air site; the suffix after the hyphen identifies an application/action. Retain both. Annual counts based on the most recently visible actions alone can change when DEQ replaces an older action. Exhaustiveness across **all past years** is not supported.

## How the release was audited

1. The [DEQ issued-permit register](https://www.deq.virginia.gov/news-info/shortcuts/permits/air/issued-air-permits-for-data-centers) exposed six fields in publicly indexed government table excerpts: facility name, registration/application, issuance date, program type, locality and regional office. The project’s direct robots preflight and the live web reader returned 403; we did not bypass it. The archived [publicly indexed government table cells](../cache/history/air/official-indexed-cells.json) are source text excerpts, **not agency HTML**. Some show the edition dated August 17; when the excerpt did not show an edition date, the field is null. Indexed snapshots can lag and overlapping excerpts are not a denominator.
2. The [Public Evidence Project's November release](https://publicevidence.org/data) supplied an independent row universe: **194 entries** as of November 9, 2026, in **19 localities**, referring to **183 registration numbers**. The [complete CSV](../cache/history/air/2026-11-09.csv) and its [data-package manifest](../cache/history/air/2026-11-09-package.json) are archived. The file’s SHA-256 and byte length match the publisher’s manifest. This attribution is required by its [CC BY 4.0 license](https://creativecommons.org/licenses/by/4.0/); the [persistent published Dataverse version](https://doi.org/10.7910/DVN/PDK5U4) is a different, July edition. November is not represented here as a directly downloaded original DEQ release.
3. The collector reconciled **190 of 194** November entries on **all six** substantive fields with agency excerpts. The comparison ignores differences in case, whitespace and punctuation (including one malformed date separator); it preserves the state text in the records. “Issued” is taken from the register’s heading, not invented as an individual permit’s present status. A DEQ document URL recovered only from the republication is labeled accordingly. For a URL attached to both 74331-1 and 74333-1 the project flags ambiguity; the register and application numbers are the citations, not the same PDF counted twice.
4. Another two IDs have state tracking records: [Cashvad 74118-4](https://permits.virginia.gov/Permit/Details/171631) and [Amazon 74342-2](https://permits.virginia.gov/Permit/Details/158317). These records say **Approved**, with an **application completion** date, so that is what the default history reports. Both dates agree with the independently republished issuance dates; that agreement does not change the date role. Cashvad is **Manassas City** in VPT and **Prince William County** in the republication. Both labels are retained with their provenance. VPT ages older details off its live public pages, so the [indexed agency fields](../cache/history/air/vpt-indexed-details.json) are preserved.
5. The remaining two entries, **52903-5 (Timber)** and **74321-2 (Belmont)**, are present in [a separate held file](../data/history/virginia/statewide/deq_air_permits/held.json). The default issue/decision history excludes them because we could not establish the new action and issue date directly from a government record. The four cases are not conflated with similarly named earlier permits. Exact ID searches of the rolling state application tracker are not a historical completeness test.
6. The source also supports **14 distinct earlier actions** absent from the November release. They remain searchable as earlier listings; absence does not establish rescission, closure or an enforcement action. The result before adding separately classified VPT applications is **206 government-backed events**: 190 matching current rows + 2 application completions + 14 earlier listings. Their dates run November 22, 2000–October 26, 2026. Of these, **204** have an agency-supported **issuance** date. Each primary event is keyed to its application number, not a normalized operator name.

**Independent government facility check.** [DEQ’s Active Air Sites ArcGIS item](https://www.arcgis.com/home/item.html?id=90b6a133362b4f94a60ec5ced47bc27d) is published by `maddie.moore_VADEQ`. The government's [downloadable Hub CSV](https://hub.arcgis.com/api/v3/datasets/90b6a133362b4f94a60ec5ced47bc27d_294/downloads/data?format=csv&spatialRefId=4326) was obtainable even though the map service returned “service not found”. We archived all 3,725 records and filtered the explicit `PLA_DATA_CENTER_YN=Y` field (159 sites). Of 183 registered sites in the November issue inventory, 151 match this export on `PLA_REG_NUM`; 32 occur only in the issue inventory and eight only in the flagged-sites set. See [the crosswalk](../data/history/virginia/statewide/deq_air_permits/site_crosswalk.json). The ArcGIS item's **metadata** last modified July 2; the CSV does not supply a comparably dated permit action for each site. A missing site in this join does not disprove an issue record. The older five-digit Timber site exists in the official export; that does not verify action **52903-5**.

## Reproducibility

`python3 scripts/collectors/virginia/statewide/deq_air_permits.py --check` verifies cached government evidence, the archived inventory hash from its own publisher, local archived inputs, unique action IDs, the full 194-row disposition and deterministic output. Omit `--check` to rebuild. The output is chronologically sorted. The source's own tabular order is by registration, not by year. Earlier rows and overlapping snapshot extracts are deduplicated by complete registration/application identifier. Action dates must parse and may not be later than a known source edition. Build fails on duplicate IDs in the republication.

For a newly authorized official capture, run `python3 scripts/collectors/virginia/statewide/deq_air_permits.py --html YOUR_OFFICIAL_SAVED_PAGE.html` or `python3 scripts/collectors/virginia/statewide/deq_air_permits.py --fetch` where the site permits it. These modes save the original HTML bytes by hash and produce a **separate dated output**, rather than overwriting the pinned release. Deployment on another jurisdiction uses `--config <path>` to change heading/column aliases, allowed government document hosts, record number grammar, date formats, source URL, state and label. `constant_fields` can supply jurisdiction or region when fixed by the source; `allow_missing_date` allows null for genuinely undated entries. An optional status column can replace the single register-wide status. The parser locates the matching table by headers, follows only declared columns for citation links, preserves date strings, and rejects ambiguous tables, unexpected columns, duplicate numbers and future dates. A synthetic city register with reordered columns, mixed statuses, an undated row, different keys and relative document links was successfully parsed; corrupted variants were rejected. No live test of a second state's issued-air HTML table is implied.

If reproducibility must mean **direct archived government HTML for every current row**, this release does not meet that narrower bar. Supply a permitted saved register page or obtain the export from DEQ; the HTML mode and the two held rows allow that upgrade without altering the historical snapshot. Nothing in these outputs estimates generator emissions, MW, facility counts, zoning restrictions or application processing times.

## State application receipts are a distinct event series

The [Virginia Permit Transparency search](https://permits.virginia.gov/Permit/Search) is an applications tracker. Its rolling display is not a replacement for the issued register. The full search-result payloads for the configured queries are [preserved here](../cache/history/air/vpt-rolling-search.json). Queries included “data”, two site aliases, ten operator/brand names and the two uncorroborated action numbers. The public table's pagination/count was checked per query. Filter agency **DEQ** and program **Air Permits**, deduplicate by the government's numeric VPT ID, and use the explicit application received timestamp. Thus a row marked **Complete / Approved** still has a **receipt** date in this event series; no approval date is inferred from it.

The queries returned 27 distinct DEQ air applications. The [23 accepted applications](../data/history/virginia/statewide/deq_air_permits/applications.json) include 22 associated with official data-center history or the state site inventory by exact registration number, and one associated with the identically named [Army Corps Northeast Creek project notice](https://www.nao.usace.army.mil/Media/News-Stories/Article/3952905/nao-2024-01939-amazon-data-services-louisa-virginia/) and locality. At capture, 21 were In Progress and two Complete. Their status and permit-status fields remain separate. All related issued-register IDs are retained under `same_facility_history_ids`; exact action links require the suffix to agree, and none of these 23 receipts has an identical action number in this issue sample. Four [official application leads](../data/history/virginia/statewide/deq_air_permits/application_leads.json) are excluded because neither the name of a data company nor a brand/code by itself proves the air source is a data center.

The main [history file](../output/history/virginia/statewide/deq_air_permits.json) contains **229 distinct events**, partitionable by `dataset` and `date_role`: 204 DEQ issuance dates, two state tracker approval-completion dates and 23 state application-received dates. The separate applications JSON is the same 23 events; do **not** concatenate it again. To repeat the live public VPT search, run `python3 scripts/collectors/virginia/statewide/deq_air_permits.py --refresh-vpt`; it uses the shared water collector's public-table downloader and saves a new hashed raw search instead of changing the audited release. Changes in rolling results are expected.
