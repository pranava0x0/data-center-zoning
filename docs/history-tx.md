# Texas: where to look, and what the permit records show

The November 15, 2026 collection has **650 government records in 12 named places**. There are 632 distinct (register, record number) pairs. Neither number counts facilities: a campus can have many permits and a permit can have multiple dated actions. [Record export](../output/history/texas/history.json) · [Validation results](../data/history/texas/validation.json) · [Archive and query manifest](../data/history/texas/manifest.json) · [County and city ranking](../data/history/texas/rankings.csv).

**Geographic priority.** The [Pacific Northwest National Laboratory IM3 Atlas](https://im3.pnnl.gov/datacenter-atlas) provides a public, reproducible existing-asset proxy. The [pinned November 5 source](https://github.com/IMMM-SFA/datacenter-atlas/blob/fe4d8420f9fdc7b16b82b8461c5e4c39b93d8f1d/static/im3_datacenter_centroids.geojson) has 220 Texas geometries out of 1,850 nationally: **205 building, 12 campus and 3 point** records in Texas. Count one source marker, not one campus, megawatt, planned project or energized connection. Multiple buildings favor large campuses; absence of an inventory marker is not evidence of no facilities. We do not aggregate the Atlas's modeled scenarios into existing assets.

The script uses the inventory county string and a point-in-polygon join to [Census 2024 Texas place boundaries, 1:500,000](https://www2.census.gov/geo/tiger/GENZ2024/shp/cb_2024_48_place_500k.zip). The latter category is not proof of legal unincorporated status on the snapshot date. Generalization and annexations affect edge cases. Taylor's count alone does not establish an Abilene city count. County-to-city assignments for permits are not inferred from approximate boundaries or a city name. County is kept only when a government project record supplies it.

**What the records mean.** An [Austin exterior pad for a modular facility](https://abc.austintexas.gov/web/permit/public-search-other?t_detail=1&t_selected_folderrsn=13676519) is building work. A [Houston data-center power fit-out](https://www.tdlr.texas.gov/TABS/Projects/TABS2024005712) is a state accessibility filing. [Abilene's first Project Ludicrous data hall](https://www.tdlr.texas.gov/TABS/Projects/TABS2024023596) and [its second building](https://www.tdlr.texas.gov/TABS/Projects/TABS2025000049) have different registration numbers. [Red Oak's operations building](https://www.tdlr.texas.gov/TABS/Projects/TABS2025010215) serves adjacent data centers; it is not itself identified as a new data hall. [TDLR program guidance](https://www.tdlr.texas.gov/media/pdf/EAB-at-a-glance.pdf) describes this separate accessibility program. A current status of Closed or Review Complete is not a certificate of occupancy, construction or county zoning consent.

**Date and classification validation.** Fort Worth's published GIS fields are File_Date, Current_Status and Status_Date. A file can have different dated statuses. 181 records use the actual status date; six use the actual file date because the source's 1900-01-01 status value predates filing by over a century and is unusable. The six carry the source status but *not* its date. This register does not give an issue date field. The validation reconciles the 225 listed GIS IDs against fetched records, hashes each of 35 archived inputs, rejects inconsistent duplicate identities and checks date ranges. San Antonio's 90 secondary rows preserve each linked trade or address locator. All Socrata and CKAN candidate totals are independently counted before paging on refresh. Signed approval letters were not available for every index record; this is register-backed evidence with field-level meanings, not a legal conclusion.

**Discovery and limits.** The city queries check project label, work description or land-use fields as each source permits. The server retrieves broad character patterns; the local screen requires an explicit center/centre/hall, computer center or server-farm phrase, including spacing, hyphenation and issuer-specific slash/camel-case variants. A call center and a data room elsewhere in the same narrative are not a match. The [18 rejected candidates](../data/history/texas/exclusions.json) are retained for review. An explicit match can describe a primary facility, an internal room, tenant alterations, a contractor's named project or supporting infrastructure; treat it as a related administrative record, not proof of principal land use. Opaque names, unnamed related trade records and unrelated records sharing a street were not inferred. Only San Antonio's project label was available in the issued registers. Austin's May 2026 last matched date is not its data-as-of date or evidence of development stopping.

There is no Texas-wide municipal permit search here. Dallas, Austin, Fort Worth and San Antonio have repeatable register searches. TDLR is a selected, expandable project-ID list, **not** a census or city permit series for Houston, Red Oak, Abilene, Richardson, Plano, Allen, Garland or Castroville. Its bulk search returned a login page to the programmatic POST, so no indiscriminate crawling or guessing identifiers was used. The Abilene page rejected direct automated HTTP access; the output preserves a short, source-linked, [reviewed government web-reader excerpt](../cache/history/tx/abilene-government-reader.json), not an original HTML archive. Its plans require renewed review on source refresh. Texas state air, stormwater, water rights, utility interconnection and municipal zoning outside the selected cases remain independent searches. Nothing here shows that every layer approved a project.

**Reproduce and extend.** From the project folder, run:

```sh
python3 scripts/collectors/texas/history.py             # verify all archive hashes and rebuild the history, ranking and QA files
python3 scripts/collectors/texas/history.py --refresh   # replace cached government API responses/registration pages and rebuild
```

[Configuration](../data/history/texas/config.json) pins the lab source, Census boundary, permit endpoints, fields and seed registrations. A refresh does not reacquire Abilene's manually reviewed excerpt. Preserve or copy the project before live refresh if you need both snapshots. [Script](../scripts/collectors/texas/history.py) uses Python's standard library: sequential counted Socrata pages (Dallas/Austin), enumerated ArcGIS IDs then bounded batches (Fort Worth), counted CKAN SQL pages (San Antonio), and labeled official HTML fields (TDLR). It fails when source schemas or coverage break rather than silently estimating counts. The manifest's hash identifies saved bytes (compressed where indicated). Current evidence has a November 15, 2026 cutoff. Update the cutoff intentionally to release a new version. A new provider can reuse the acquisition pattern, but status meaning, jurisdiction roles, sector inclusion criteria, dates and local IDs must be checked with the publisher.
